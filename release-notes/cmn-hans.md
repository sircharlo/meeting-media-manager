# 更新内容

关于各版本之间完整的更改清单，请参阅 GitHub 上的 CHANGELOG.md 文件。

## 即将发布的版本

### ✨ 新功能

- ✨ 会前/会后快捷操作：新增大按钮操作面板，方便在聚会开始前和刚结束后快速完成常用操作，包括实时倒计时、一键开始或停止背景音乐、开始或停止录制，以及按类别整理的会众专用检查清单。每个会众都可以使用独立的检查清单，并可在“设置”中编辑。 会前操作面板会在聚会开始且检查清单全部完成后自动关闭；如果仍有未完成的项目，也会在短暂的宽限时间后自动关闭。用户也可以随时手动关闭该面板。

## v26.8.0

### ✨ 新功能

- - ✨ **应用程序整体重新设计**：全面更新了对话框、媒体列表和标题、设置以及初始设置向导的视觉设计和交互方式。 初始设置向导现在采用每个画面只显示一个问题的流程，并增加了进度条。 所有提示窗口都改为统一风格的对话框；导入出版物或通过拖放导入 PDF 时，页面范围选择也从手动输入改为使用缩略图网格选择。 完成初始设置向导后，还新增了“快速入门指南”导览。 此外，也更新了卡片和标题样式，阴影效果会配合深色模式，并修复了多处深色模式的对比度问题，例如获得焦点的字段标签和下载进度百分比。
- ✨ **设置页面**：重新设计为双栏布局，并新增全局“偏好设置”部分。自动更新和测试版更新开关已从“关于”对话框移到这里，“关于”页面现在只显示应用程序信息。
- ✨ **添加更多媒体按钮**：新增设置，可以精确选择哪些聚会部分显示“添加更多媒体”快捷按钮；另外还可以启用紧凑模式，只显示图标。
- ✨ **媒体列表**：添加媒体项目时，现在会先显示加载占位效果，而不会暂时显示为空白。媒体组的标记会显示隐藏项目的数量，例如“9 个项目（隐藏 2 个）”。组内项目现在可以通过拖放重新排序；窗口非常窄时，媒体项目会自动缩小为带有工具提示的紧凑标签，避免挤在同一行。

## v26.7.7

### ✨ 新功能

- ✨ **媒体预览质量**：媒体预览现在通过 Canvas 渲染视频画面，并使用高质量缩放，改善预览画面中的锯齿和模糊问题，尤其是诗歌等文字较多的视频。如果同一个视频的预览多次出现播放不同步并需要反复校正，媒体预览会自动关闭，以避免影响计算机性能，并提供一键重新启用的方式。 预览如果必须在单个视频上反复纠正回放漂移，也会自动禁用自身， 用单击方式重新打开它。

## v26.7.6

### ✨ 新功能

- ✨ **排除会众研经班视频**：新增设置，可以排除指定出版物在会众研经班中使用的视频。默认排除《鼓起勇气与上帝同行》，并提供可搜索的出版物选择器。

## v26.7.4

### ✨ 新功能
