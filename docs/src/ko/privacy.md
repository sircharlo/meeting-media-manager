# 개인정보 처리방침 {#privacy-policy}

시행일: 2026년 11월 22일

Meeting Media Manager(M³)는 자원봉사자들이 만든 무료 오픈 소스 프로그램입니다. 이 방침은 M³가 어떤 데이터를 처리하며 그 데이터가 어디로 가는지 설명합니다. It applies to every version of M³: the installers and portable version from this website, and the versions in the Microsoft Store and the Snap Store.

**요약하면:** M³에는 계정도, 광고도, 광고나 마케팅 목적의 추적 도구도 없습니다. 설정과 미디어는 사용자의 컴퓨터에 그대로 남아 있습니다. M³는 문제를 찾아 해결할 수 있도록 오류 보고서, 그리고 각 세션과 M³의 실행 속도에 관한 정보로 이루어진 진단 데이터를 개발자에게 보냅니다. 이때 M³는 사용자나 사용자의 회중을 식별할 수 있는 정보를 제외하며, 사용자의 IP 주소는 저장되지 않습니다.

## 사용자의 컴퓨터에 남는 정보 {#on-your-computer}

M³는 사용자의 컴퓨터에 있는 자체 데이터 폴더에 다음 정보를 보관합니다.

- 각 회중 또는 그룹의 설정(예: 이름, 집회 일정, 언어, 연동 기능)
- M³가 다운로드하는 미디어와 출판물, 그리고 사용자가 추가하는 미디어
- OBS Studio 비밀번호(OBS Studio를 사용하는 경우). M³는 운영 체제의 비밀번호 저장소를 사용할 수 있으면 이를 사용해 비밀번호를 암호화하고, 사용할 수 없으면 비밀번호를 평문으로 저장하고 그 사실을 알려 줍니다.
- Zoom 연동 설정(Zoom 연동을 사용하는 경우)

오류 보고서에는 이 설정 중 일부가 포함되지만(아래 참조), 사용자나 사용자의 회중을 식별할 수 있는 설정은 절대 포함되지 않습니다.

미디어 창에 카메라 영상을 표시하는 경우(수어 회중을 위한 옵션), 그 영상은 표시되기만 할 뿐 M³가 녹화하거나 저장하거나 전송하지 않습니다. M³가 보여 주는 미디어 창 미리 보기는 사용자의 컴퓨터에서 캡처되며, 이 역시 저장되거나 전송되지 않습니다.

M³의 데이터 폴더를 삭제하면 언제든지 이 모든 정보를 삭제할 수 있습니다. Windows에서는 M³를 제거할 때도 데이터 폴더가 삭제됩니다. The Snap Store version keeps it when you uninstall it, unless you ask it not to (`snap remove --purge`).

## 진단 데이터 {#error-reports}

M³는 개발자들이 버그를 찾아 수정하는 데 사용하는 서비스인 [Sentry](https://sentry.io)로 진단 데이터를 보냅니다.

**오류 보고서**는 M³에서 문제가 발생했을 때 전송됩니다. 보고서에는 다음 정보가 포함될 수 있습니다.

- 오류, 그리고 오류가 발생한 M³ 코드의 위치
- M³ 버전, 운영 체제와 그 버전, 언어 및 시간대, 그래픽 카드 등 하드웨어에 관한 기본 정보
- M³에서 열린 페이지, 다운로드 중이던 파일 등 오류가 발생하기까지의 과정
- 당시 M³의 상태: 설정, 그리고 재생 중이던 미디어나 준비 중이던 집회 등 M³가 하고 있던 작업
- M³의 일부에서 충돌이 발생한 경우, 충돌 시점의 메모리 일부가 포함될 수 있는 해당 부분의 충돌 보고서

**세션 정보**는 M³가 실행될 때마다 전송되며, 시작 시각, 정상 종료 또는 충돌 여부, M³ 버전과 운영 체제가 포함됩니다.

**성능 정보**는 모든 세션에서 전송되며, M³의 페이지가 열리는 데 걸리는 시간과 M³가 아래 서버로 보내는 요청에 걸리는 시간이 해당 서버 주소와 함께 포함됩니다.

### M³가 제외하는 정보 {#left-out}

M³는 진단 데이터를 보내기 전에 사용자나 사용자의 회중을 식별할 수 있는 다음 정보를 제거합니다.

- 회중 이름, 회중의 Zoom 회의 ID, Zoom 참여자 이름
- 설정 PIN과 OBS Studio 비밀번호
- 사용자의 컴퓨터에 있는 폴더 및 파일 이름(폴더는 드라이브 또는 최상위 폴더만, 파일은 형식만 남음)
- "웹사이트 주소" 설정의 주소(기본 주소가 아닌 경우)
- 보고서의 폴더 경로에 포함된 사용자 이름

M³에는 이름, 이메일 주소, 계정이 없으므로 데이터에도 이런 정보는 포함되지 않습니다. M³는 Sentry에 IP 주소를 기록하지 않도록 요청하며, Sentry도 IP 주소를 저장하지 않도록 설정되어 있습니다.

M³ 개발진은 문제를 찾아 해결하는 목적으로만 이 데이터를 사용합니다. Sentry는 이 데이터를 미국에 저장하며 일정 기간이 지나면 삭제합니다. Sentry가 이 데이터를 어떻게 처리하는지는 [Sentry 개인정보 처리방침](https://sentry.io/privacy/)에서 설명합니다.

## M³가 연결하는 서버 {#connections}

M³는 작업을 수행하기 위해 아래 서버에 연결합니다. 사용자가 방문하는 모든 웹사이트와 마찬가지로, 이 서버들은 사용자 컴퓨터의 IP 주소를 볼 수 있습니다.

- **여호와의 증인 공식 웹사이트**와 그 다운로드 서버: 집회 미디어와 출판물 및 관련 정보를 다운로드합니다. 이 웹사이트가 받는 정보에는 해당 웹사이트의 자체 개인정보 처리방침이 적용됩니다.
- **GitHub**: M³가 게시되는 곳으로, M³의 업데이트를 확인하고 다운로드하며 M³의 새로운 점을 보여 줍니다. The Microsoft Store and Snap Store versions get their updates from their store instead.
- **jsDelivr**: 일부 언어에 필요한 글꼴과 M³가 PDF 파일을 읽는 데 사용하는 구성 요소를 다운로드합니다.
- **Apple, Cloudflare, icanhazip.com 및 ipify.org**: 컴퓨터가 인터넷에 연결되어 있는지 확인합니다.
- **Sentry**: 위에서 설명한 진단 데이터를 보냅니다.

또한 M³는 다음 항목을 사용하는 경우 사용자의 컴퓨터나 로컬 네트워크에서 이들과 함께 작동합니다.

- **Zoom:** M³가 사용자의 컴퓨터에 있는 Zoom 앱을 제어합니다. M³ 자체는 Zoom 서버로 아무것도 보내지 않습니다.
- **OBS Studio:** M³가 사용자의 컴퓨터나 로컬 네트워크에 있는 OBS Studio에 연결합니다.
- **원격 타이머:** 다른 기기에서 집회 타이머를 표시할 수 있도록 M³가 로컬 네트워크에서 작은 웹 서버를 실행합니다.

M³의 웹사이트 창에 여호와의 증인 공식 웹사이트를 표시하면, 이 웹사이트는 웹 브라우저에서와 같은 방식으로 작동합니다.

## 스토어 {#stores}

If you install M³ from the Microsoft Store or the Snap Store, that store handles its installation and updates, under its own privacy policy. M³ 자체는 모든 버전에서 똑같이 작동합니다.

## 이 방침의 변경 {#changes}

M³가 데이터를 처리하는 방식이 바뀌면 이 페이지가 업데이트되며, 맨 위에 새 날짜가 표시됩니다. 이 페이지의 변경 기록은 [GitHub](https://github.com/sircharlo/meeting-media-manager/commits/master/docs/src/en/privacy.md)에서 볼 수 있습니다.
