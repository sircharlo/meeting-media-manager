# 隐私政策 {#privacy-policy}

生效日期：2026年11月22日

Meeting Media Manager（M³）是一款由志愿者开发的免费开源应用程序。本政策说明 M³ 会处理哪些数据，以及这些数据的去向。本政策适用于 M³ 的所有版本：本网站提供的安装程序和便携版，以及 Microsoft Store 和 Snap Store 中的版本。

\*\*简而言之：\*\*M³ 没有账户，没有广告，也没有广告或营销跟踪器。你的设置和媒体都保留在你的计算机上。为了发现和修复问题，M³ 会向其开发者发送诊断数据：错误报告，以及有关每次会话和 M³ 运行速度的信息。 M³ 会从中排除可能识别出你或你的会众的信息，你的 IP 地址也不会被存储。

## 哪些内容保留在你的计算机上 {#on-your-computer}

M³ 会把以下内容保存在你计算机上的 M³ 数据文件夹中：

- 每个会众或小组的设置，例如名称、聚会时间安排、语言和集成；
- M³ 下载的媒体和出版物，以及你添加的媒体；
- OBS Studio 的密码（如果你使用 OBS Studio）。当你的操作系统的密码存储功能可用时，M³ 会用它加密这个密码；不可用时，M³ 会以纯文本形式存储密码，并告诉你这一点；
- 你的 Zoom 集成设置（如果你使用 Zoom 集成）。

错误报告会包含其中一些设置（见下文），但绝不会包含可能识别出你或你的会众的设置。

如果你在媒体窗口上显示摄像头画面（这是为手语会众提供的选项），该画面只会被显示：M³ 不会录制、保存或发送它。 M³ 向你显示的媒体窗口预览是在你的计算机上捕获的，同样不会被保存或发送。

你可以随时删除 M³ 的数据文件夹，从而删除以上所有内容。在 Windows 上，卸载 M³ 也会将其删除。 Snap Store 版本在你卸载它时会保留这些内容，除非你要求它不要保留（`snap remove --purge`）。

## 诊断数据 {#error-reports}

M³ 会将诊断数据发送到 [Sentry](https://sentry.io)，这是 M³ 的开发者用来发现和修复程序错误的服务。

**错误报告**，在 M³ 出现问题时发送。一份报告可能包含：

- 错误本身，以及错误发生在 M³ 代码中的哪个位置；
- M³ 的版本、你的操作系统及其版本、你的语言和时区，以及有关你的硬件的基本信息，例如你的显卡；
- 导致错误发生的操作步骤，例如在 M³ 中打开过的页面，以及 M³ 当时正在下载的文件；
- M³ 当时的状态：它的设置，以及它正在做的事情，例如正在播放的媒体或正在准备的聚会；
- 当 M³ 的某个部分崩溃时，该部分的崩溃报告，其中可能包含崩溃那一刻该部分的一些内存内容。

**会话信息**，在每次运行 M³ 时发送：M³ 何时启动，以及是正常结束还是崩溃，同时附有 M³ 的版本和你的操作系统。

**性能信息**，在每次会话中发送：M³ 的页面需要多长时间才能打开，以及它向下列服务器发出的请求需要多长时间，同时附有这些请求的地址。

### M³ 排除的内容 {#left-out}

在发送诊断数据之前，M³ 会移除可能识别出你或你的会众的信息：

- 会众的名称、会众的 Zoom 会议 ID，以及 Zoom 参与者的姓名；
- 设置 PIN 码和 OBS Studio 密码；
- 你计算机上文件夹和文件的名称：只保留文件夹所在的驱动器或顶层文件夹，以及文件的类型；
- “网站地址”设置中的地址（当它不是默认地址时）；
- 你的用户名（出现在报告的文件夹路径中）。

这些数据不包含任何姓名、电子邮件地址或账户，因为 M³ 没有这些信息。 M³ 会要求 Sentry 不要记录你的 IP 地址，而 Sentry 也被设置为不存储它。

M³ 的维护者只会将这些数据用于发现和修复问题。 Sentry 将这些数据存储在美国，并会在一段有限的时间后将其删除。 [Sentry 的隐私政策](https://sentry.io/privacy/)说明了 Sentry 如何处理这些数据。

## M³ 连接的服务器 {#connections}

为了完成工作，M³ 会连接到下列服务器。就像你访问的任何网站一样，这些服务器可以看到你计算机的 IP 地址。

- **耶和华见证人官方网站**及其下载服务器，用于下载聚会媒体和出版物，以及它们的相关信息。该网站自己的隐私政策适用于它收到的内容。
- **GitHub**，即 M³ 的发布平台，用于检查和下载 M³ 的更新，以及显示 M³ 的新内容。 Microsoft Store 和 Snap Store 版本则从各自的商店获取更新。
- **jsDelivr**，用于下载某些语言需要的字体，以及 M³ 用来读取 PDF 文件的组件。
- **Apple、Cloudflare、icanhazip.com 和 ipify.org**，用于检查你的计算机是否已连接到互联网。
- **Sentry**，用于发送上述诊断数据。

如果你使用以下各项，M³ 还会在你的计算机或本地网络上与它们配合工作：

- \*\*Zoom：\*\*M³ 会控制你计算机上的 Zoom 应用程序。 M³ 本身不会向 Zoom 的服务器发送任何内容。
- \*\*OBS Studio：\*\*M³ 会连接到你计算机或本地网络上的 OBS Studio。
- \*\*远程计时器：\*\*M³ 会在你的本地网络上运行一个小型网页服务器，让其他设备可以显示聚会计时器。

当你在 M³ 的网站窗口中显示耶和华见证人官方网站时，它的运作方式与在网页浏览器中相同。

## 应用商店 {#stores}

如果你从 Microsoft Store 或 Snap Store 安装 M³，该商店会按照它自己的隐私政策处理 M³ 的安装和更新。 M³ 本身在每个版本中的运作方式都相同。

## 本政策的变更 {#changes}

如果 M³ 开始以不同的方式处理数据，本页面将会更新，并在顶部注明新的日期。本页面的修订历史可以在 [GitHub](https://github.com/sircharlo/meeting-media-manager/commits/master/docs/src/en/privacy.md) 上查看。
