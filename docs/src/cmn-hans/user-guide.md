# 用户指南 {#user-guide}

这份综合用户指南将帮助你从基础设置到高级媒体显示，全面掌握 M³ 的各项功能。

## 入门 {#getting-started}

### 下载与安装 {#download-and-install}

从 [下载页面](download)获取最新版本。 从 [下载页面](download) 获取最新版本。它能为您的设备推荐最佳版本并显示最新版本。

### 首次启动 {#first-launch}

第一次启动 M³ 时，会进入初始设置向导，帮助你完成重要配置：

1. **选择界面语言** —— 设置 M³ 菜单和按钮所使用的语言
2. **选择配置类型** —— 一般会众请选择“常规”，特别活动可选择“其他”
3. **配置会众信息** —— 输入会众信息，或使用会众搜索功能
4. **设置聚会时间安排** —— 设置周中聚会和周末聚会的日期与时间
5. **可选功能** —— 设置 OBS Studio 集成、背景音乐以及其他高级功能

:::tip 小贴士

请按需耐心完成设置；您也可以随时在“设置”菜单中再次修改。

:::

### 主界面概览 {#main-interface}

M³ 主界面包含以下主要区域：

- **侧边导航** —— 前往不同页面和设置
- **日历视图** —— 按日期浏览媒体
- **媒体列表** —— 查看和管理所选日期的媒体
- **工具栏** —— 快速使用常用功能
- **状态栏** —— 显示下载进度、背景音乐状态、OBS Studio 连接状态等

## 媒体管理 {#user-guide-media-management}

### 认识日历视图 {#calendar-view}

日历视图会显示聚会时间安排和可用媒体：

- **聚会日** —— 突出显示已安排聚会的日期
- **媒体提示** —— 使用图标显示可用的媒体类型
- **日期导航** —— 使用方向按钮在不同月份之间切换

### 整理媒体 {#organizing-media}

M³ 会按聚会类型和节目部分自动整理媒体：

- **聚会部分** —— 例如公众演讲、上帝话语的宝藏等
- **自定义部分** —— 即使某个日期没有安排聚会，也可以建立自定义部分并添加媒体
- **手动排序** —— 可以拖动媒体项目调整顺序，也可以根据需要重置排序
- **循环播放** —— 可以循环播放单个媒体项目，也可以重复播放某个部分中的所有媒体，直到手动停止

### 隐藏和缺失的媒体 {#hidden-and-missing-media}

可以把媒体从聚会媒体列表中隐藏，而不会删除自动下载的文件。如果误将媒体隐藏，可以在所选日期使用**显示隐藏的媒体**功能恢复显示。 If media is hidden by mistake, use **Show hidden media** for the selected day.

If M³ reports missing media, first check whether the item is expected to become available closer to the meeting date. You can also add the missing item manually with the **Add media** menu or by dragging it into the media list.

## 显示工具 {#display-tools}

### 媒体显示窗口 {#media-display-window}

媒体显示窗口是观众看到的窗口。根据设备配置，可以放在外部显示器上，也可以使用窗口模式。 It can be placed on an external screen or used in a windowed setup depending on your equipment.

Use the display popup to:

- 显示或隐藏媒体窗口
- 选择显示器或窗口类型
- 临时使用自定义背景代替全年经文
- 使用可用的摄像头画面作为背景，这主要用于手语会众 This is mostly used in sign-language congregations.

请注意，自定义背景只是临时设置，退出 M³ 后不会保留。

### 聚会计时器 {#user-guide-meeting-timer}

启用聚会计时器后，M³ 可以显示一个单独的计时器窗口，为聚会节目参与者计时。计时器可以正计时或倒计时，也可以显示当前时间、聚会开始前的倒计时，并根据设置显示超时情况，或者显示聚会整体是提前还是超时。 The timer can count up or down, show the current time, show a meeting countdown before scheduled meetings, and optionally indicate overtime or whether the meeting is ahead of or behind schedule.

计时器目前属于测试功能，只有得到当地批准后才应使用。

### 设置背景音乐 {#background-music-setup}

背景音乐可以在聚会前自动播放，并在适当的时候停止：

1. **启用背景音乐** —— 在设置中开启背景音乐功能
2. **自动开始** —— 在适当情况下，M³ 启动后自动开始播放
3. **聚会前停止** —— 在聚会开始前自动停止
4. **手动控制** —— 使用状态栏中的音乐按钮随时开始或停止
5. **重新播放** —— 聚会结束后可以快速重新开始播放

## Zoom 集成 {#user-guide-zoom-integration}

M³ 可以与 Zoom 集成，以便自动触发屏幕共享：

1. **启用集成** —— 在设置中开启 Zoom 集成
2. **配置快捷键** —— 在 Zoom 中设置“开始/停止屏幕共享”的快捷键，并将其设为全局快捷键 请确保已勾选“全局快捷键”
3. **自动控制** —— 当 M³ 开始或停止播放媒体时，会自动触发 Zoom 开始或停止屏幕共享
4. **配置快捷键** —— 在 Zoom 中设置屏幕共享快捷键 ，并勾选“全局快捷键”

### 混合聚会音频配置 {#audio-configuration}

当 OBS Studio 用于混合聚会（现场 + Zoom）时，需要正确配置音频，才能让 Zoom 参与者听到媒体声音。

#### Zoom 音频设置 {#zoom-audio-settings}

**检查音频** —— 混合聚会时，确认 Zoom 可以正常接收到媒体声音

1. **打开 Zoom** → **设置**
2. 进入 **音频** → **高级**
3. 勾选 **“在会议内显示‘启用原始音频’选项”**
4. 勾选 **“禁用回声消除”**（第一项）
5. 勾选 **“禁用噪声抑制”**（第二项）
6. **不勾选** **“禁用高保真音乐模式”**（第三项）
7. **每次聚会开始前**，在会议控制条中点击“Original Audio/原始音频”按钮

**共享计算机声音**：如果适合当前设备配置，可以把它作为另一种方案

1. **播放媒体前**，在 Zoom 的共享界面切换到 **“高级”** 选项卡
2. **替代方案：共享计算机声音**
3. **注意**：每次新开 Zoom 会话都要重新开启

**更简单的替代方案**：可以考虑使用 M³ 的 Zoom 集成。它使用 Zoom 原生屏幕共享，音频处理通常更加直接。

#### 为什么需要这些设置 {#why-audio-config}

M³ 会在计算机上正常播放带声音的媒体，但 OBS Studio 的视频输出本身不会自动把这些声音一起传给 Zoom。视频输出的工作方式类似一个没有声音的虚拟摄像头。 这是与任何其他媒体播放器相同的行为。

**音频问题与 M³ 无关** —— 这是 OBS Studio 视频流与 Zoom 配合使用时的一个限制。 视频流像一个没有声音的虚拟摄像头，因此您必须明确配置缩放来捕捉计算机的音频。 这意味着您的计算机有两个声音卡，如果不是这样，就有两个声音卡了。 您可能无法成功使用 OBS 工作室集成。

**更简单的方案**：也可以考虑使用 M³ 的 Zoom 集成。它使用 Zoom 原生的屏幕共享功能，因此音频处理通常更加直接。

#### 音频疑难解答 {#audio-troubleshooting}

**常见问题：**

- **音质不理想**：检查 Zoom 的原始音频和音频处理设置
- **音质不理想**：检查 Zoom 的原始音频和其他音频处理设置
- **重新开始 Zoom 聚会后失效**：再次确认音频设置

**建议做法：**

- 聚会前测试完整的音频路径和共享设置
- 准备一份音频设置检查清单，方便人员交接
- 把“共享电脑声音”当作备选方案
- 使用 OBS Studio 时，需要让 Zoom 能接收到计算机播放的媒体声音。具体设置会根据计算机和音频设备的配置而有所不同。
- 确保负责音视频操作的人员熟悉这些设置

## 导入自定义媒体 {#importing-custom-media}

### 媒体导入和管理 {#media-import}

向 M³ 添加自己的媒体文件：

1. **添加媒体** —— 使用添加媒体功能加入视频、图片或音频

## 疑难解答 {#troubleshooting-guide}

### 常见问题 {#common-issues}

#### 无法下载媒体 {#user-guide-media-not-downloading}

- 检查聚会时间安排是否正确
- 确认网络连接正常
- 确认所选语言有相应媒体

#### OBS Studio 集成无法使用 {#user-guide-obs-not-working}

- 检查 WebSocket 功能是否已经正确配置
- 检查端口和密码设置
- 确保 OBS Studio 正在运行

#### Zoom/OBS Studio 音频问题 {#audio-issues}

- 如果使用 Zoom 的\*\*原始音频（Original Audio）\*\*功能，请先在 Zoom 的音频设置中启用相关选项，并在聚会开始后确认原始音频已经开启。
- **Zoom 没有声音**：检查 Zoom 是否能够接收到计算机播放的媒体声音
- **重新开始 Zoom 聚会后没有声音**：确认新聚会中的音频设置是否仍然正确
- 如果当前设备配置适合使用 Zoom 的原生共享功能，也可以使用**共享计算机声音**，让 Zoom 直接共享计算机播放的音频。

#### 性能问题 {#user-guide-performance-issues}

- 启用额外缓存
- 降低最高视频分辨率
- 清理旧缓存文件
- 检查可用磁盘空间
- 如果出现图形异常或崩溃，可以尝试禁用硬件加速，然后重新启动 M³

#### 语言问题 {#user-guide-language-issues}

- 检查界面语言

## 最佳做法 {#best-practices}

### 聚会前 {#before-meetings}

1. **检查下载** —— 确认所有需要的媒体都已经下载完成
2. **测试设备** —— 检查显示和音频是否正常
3. **准备媒体** —— 查看并整理本次聚会所需的媒体，确认没有缺失
4. **替代方案**：根据设备配置使用 Zoom 的“共享计算机声音”

### 聚会期间 {#during-meetings}

1. **专注操作** —— 使用简洁的界面，减少不必要的干扰
2. **熟悉快捷键** —— 练习并熟悉常用快捷键
3. **留意音频** —— 如果负责音视频操作，请注意音量和音质
4. **准备下一项** —— 提前确认下一个要播放的媒体
5. **确认线上音频** —— 确认 Zoom 参与者能够听到媒体声音

### 聚会后 {#after-meetings}

1. **恢复背景音乐** —— 如有需要，重新开始播放
2. **准备下次聚会** —— 检查下一次聚会的媒体
3. **整理收尾** —— 在适当的时候关闭媒体窗口和其他相关窗口

### 日常维护 {#regular-maintenance}

1. **更新 M³** —— 及时安装最新版本
2. **清理缓存** —— 定期清理不再需要的缓存文件
3. **检查设置** —— 根据实际需要调整配置
