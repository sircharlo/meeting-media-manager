# 关于 Meeting Media Manager (M³) {#about-meeting-media-manager-m3}

## 这个应用程序是什么？ 这个应用程序是什么？ {#what-is-this-app}

**Meeting Media Manager**，简称 **M³**，是一款适用于 Windows、macOS 和 Linux 的综合性跨平台应用程序，可以自动下载、整理和播放耶和华见证人会众聚会所需的图片和视频。它支持耶和华见证人官方网站提供的各种语言，并提供适用于混合聚会和现场聚会的媒体管理工具。 它支持耶和华见证人官方网站上的任何语言，并为混合聚会和线下聚会期间管理媒体，提供强有力的工具。

M³ 可以管理常规聚会和自定义聚会的媒体，也支持在同一个计算机账户中为多个会众或小组建立不同配置。此外，它还提供多种媒体显示功能，让聚会期间播放和共享媒体更加方便。

:::info 备注

此应用程序以前称为 JWMMF（JW Meeting Media Fetcher），于 2022 年 5 月更名为 Meeting Media Manager。

:::

## M³ 能做什么？ {#what-can-m3-do} {#what-can-m3-do}

M³ 是一套完整的聚会媒体管理工具，可以帮助你自动下载、同步、整理、共享和显示聚会所需的媒体。 以下是M³的强大之处：

### 核心媒体管理

- **自动下载媒体**：自动获取并下载即将举行的聚会所需的媒体
- **多语言支持**：可以下载耶和华见证人官方网站所提供的各种语言版本
- **智能缓存**：使用缓存系统整理媒体，并保持媒体内容更新
- **媒体整理**：按照日期和聚会节目自动整理媒体

### 媒体播放功能 {#about-presentation-features}

对于**混合聚会**或**现场聚会**，M³ 提供以下媒体显示功能：

- **高级媒体控制**：方便选择和控制媒体，并支持缩放和平移
- **自定义播放时间**：可以设置媒体的自定义开始和结束时间
- **播放控制**：提供播放、暂停和停止按钮，并支持键盘快捷键
- **实时预览和播放速度控制**：可以预览观众所看到的媒体窗口，并根据需要调整音频或视频的播放速度
- **多显示器支持**：自动检测并管理外部显示器
- **简洁的媒体显示**：向观众显示媒体时不会出现不必要的界面元素

### 背景音乐

- **自动控制**：背景音乐可以在聚会开始前自动停止
- **快速重新播放**：聚会结束后可以方便地重新开始播放背景音乐
- **音量控制**：可以单独调节背景音乐音量

### Zoom 集成

- **自动触发屏幕共享**：媒体开始或停止播放时，可以自动触发 Zoom 的屏幕共享功能

### OBS Studio 集成

- **自动切换场景**：可以与 OBS Studio 集成，用于混合聚会
- **场景管理**：可以在摄像头、媒体和其他场景之间自动切换
- **录制控制**：启用后，可以直接从 M³ 开始或停止 OBS Studio 的录制

### 媒体导入和管理

- **JWPUB 文件**：可以导入和管理 JWPUB 文件
- **JW Library 播放列表**：支持从 JW Library 导出的播放列表文件
- **自定义媒体**：可以导入视频、图片、音频文件和 PDF 文件
- **圣经媒体**：可以导入研读本圣经的媒体、手语圣经媒体，以及《新世界译本》的录音
- **公众演讲**：可以通过 S-34 或 S-34mp 文件准备公众演讲所需的媒体

### 高级功能

- **文件夹监视**：可以自动从指定文件夹（例如 Dropbox、OneDrive 等同步文件夹）导入媒体
- **媒体导出**：可以自动将媒体按日期整理并导出到指定文件夹
- **网站展示**：可以在外部显示器上展示耶和华见证人官方网站
- **聚会计时器**：可以使用单独的计时器窗口为聚会节目计时
- **聚会录制辅助功能**：可以控制 OBS Studio 或其他外部录制应用程序
- **键盘快捷键**：可以为多种功能设置自定义快捷键
- **多个配置**：可以分别管理不同会众或小组的配置，并支持导入和导出配置设置

## M³ 支持我的语言吗？ {#does-m3-work-in-my-language} {#does-m3-work-in-my-language}

**支持！** M³ 提供广泛的多语言支持。

聚会媒体可以自动下载耶和华见证人官方网站所提供的各种语言版本。可用语言列表会动态更新，你只需要在设置中选择需要的媒体语言。 可用语言列表会动态更新；您只需在设置期间选择所需的语言即可。

### 界面语言

M³ 本身也已经由志愿者翻译成多种语言。界面语言和媒体下载语言可以分别设置，因此你可以使用自己习惯的语言操作 M³，同时下载另一种语言的聚会媒体。 您可以配置希望在M³界面中显示的语言，独立于用于媒体下载的语言。 这意味着您可以使用首选语言操作 M³，同时下载任何其他支持语言的媒体。

关于备用媒体语言和字幕语言的详细说明，请参阅 [FAQ](faq#language-support)。
