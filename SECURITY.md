# Security Policy

## Supported Versions

The latest version of the app will always be the only one supported, as it automatically updates on launch anyways.

| Version        | Supported          |
| -------------- | ------------------ |
| latest release | :white_check_mark: |
| older release  | :x:                |

## Reporting Vulnerabilities

If you find a security vulnerability, please report it privately using GitHub's [private vulnerability reporting](https://github.com/sircharlo/meeting-media-manager/security/advisories/new) (Security tab → "Report a vulnerability"), rather than a public GitHub Issue. This keeps the details confidential while a fix is developed. It will be addressed quickly.

For non-sensitive bugs that aren't security vulnerabilities, GitHub Issues remains the right place.
